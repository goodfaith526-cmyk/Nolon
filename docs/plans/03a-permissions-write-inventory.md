# ملحق 03a: جرد مداخل الكتابة (F114-1، F114-4)

**المصدر:** main عند `a3624d2`. مُولَّد من شجرة TypeScript (AST) لكل `class` عليه `@Controller` ولكل method عليها `@Post/@Patch/@Put/@Delete`: البادئة من `@Controller` نفس الـ class (الملف الواحد قد يحمل عدة controllers، مثل `billing.controller.ts`)، واسم المعالج هو اسم الـ method (ما دوال `FileInterceptor` داخل `@UseInterceptors`). النتيجة: 239 مدخلاً في 43 ملفاً، **بلا تصادم** في المفتاح `الفعل + المسار`. المسارات بدون البادئة العامة `/api/v1`.
